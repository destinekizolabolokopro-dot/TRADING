POUR OUVRIR (le plus simple)
----------------------------
1. Décompresse ce dossier ZIP quelque part (Bureau, Documents…).
2. Double-clique sur le fichier :  index.html
3. Ça s'ouvre dans ton navigateur (Chrome, Edge, Firefox…).
   -> La CRYPTO (BTC/USD, ETH/USD, SOL/USD) s'affiche en DIRECT
      immédiatement, sans rien configurer.

POUR ACTIVER LE FOREX ET L'OR (GBP/USD, USD/JPY, EUR/JPY, XAU/USD, XAU/EUR)
--------------------------------------------------------------------------
Ces marchés en temps réel nécessitent une clé API GRATUITE :
1. Va sur :  https://twelvedata.com/register
2. Crée un compte gratuit (30 secondes) et copie ta clé API.
3. Dans TRADEassist, colle la clé dans le champ "Clé API forex / or"
   puis clique "Enregistrer". La clé reste sur ton appareil.

CE QUE TU PEUX FAIRE
--------------------
- STATISTIQUES en haut : nombre de setups, achats/ventes, confiance et R:R moyens.
- FILTRES : direction (achat/vente), marché (crypto/forex/or), tri (confiance/R:R/nom).
- CLIQUE SUR UNE CARTE -> ouvre le GRAPHIQUE en chandeliers avec tous les
  niveaux (Fibonacci, zone OTE, FVG, Entrée/Stop/TP, liquidité) + le
  calculateur de risque et les confluences.
- BOUTON RISQUE (⚙) : entre ton capital et ton risque % -> la taille de
  position suggérée s'affiche sur chaque signal.
- CLOCHE (🔔) : active les alertes (son + notification) à chaque nouveau setup.
- LUNE/SOLEIL : bascule thème sombre / clair.
- WATCHLIST : change les paires (seules les 8 prévues sont acceptées).
- UNITÉ DE TEMPS : 5m / 15m / 1h / 4h.

LES DEUX STRATÉGIES
-------------------
  STRATÉGIE 1 — "OTE + PD Array + CRT" :
     zone OTE (0.62-0.79) du Fibonacci
     + PD Array (Fair Value Gap ou Order Block) en zone discount/premium
     + CRT OBLIGATOIRE (prise de liquidité + retour)

  STRATÉGIE 2 — "Previous Daily CRT" :
     balayage du plus-haut / plus-bas de la VEILLE (PDH/PDL) + retour.

Plus il y a de confluences dans le même sens, plus la CONFIANCE (%) est élevée.
Un signal n'apparaît qu'avec un Risk:Reward >= 1.2. Filtre par stratégie en haut.
Le site est en BLANC par défaut (bouton soleil/lune pour basculer).

Le site se met à jour tout seul (crypto ~40 s, forex/or ~4 min).
